# V11.3 second-lap ring loss fix

Date: 2026-10-04

This change is based on V11.2 and only touches roundabout recovery behavior observed in the second-lap log.

Changes:

1. After the real exit marker is confirmed, the 2.00s main-line pass window keeps a minimum 0.32 m/s when the dashed main line is temporarily lost. This prevents generic persistent recovery from reducing the car to ~0.07-0.14 m/s before FAST_ENTRY.
2. The exit-zone lost-line forced-left gate is moved from 220 deg to 200 deg. The observed second lap peaked at ~217 deg and then inherited a rightward recovery, causing integrated turn to decrease. From 200 deg onward, lost-line recovery stays LEFT.
3. After ROUNDABOUT_EXIT completes, all exit sources (gyro / vision / timeout) use the same no-line search while the short post-exit guard is active: 0.24 m/s and `roundabout_post_exit_loss_left_turn` (0.50 rad/s). Once line_valid returns, normal frame-by-frame following resumes immediately.

Unchanged:

- 330 deg exit heading lock
- 360 deg target heading and tolerance logic
- 1.50s suspicious-left gyro hold
- FAST_ENTRY timing/turn parameters
- normal patrol, crosswalk, step, finish logic
