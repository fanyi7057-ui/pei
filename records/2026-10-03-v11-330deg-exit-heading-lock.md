# V11：330°出口航向锁

基线：`good3(环岛出口误判进二次)` / V10。

实车日志关键点：

- `turn≈215°` 仍有线；`234°` 开始出口区域连续丢线，V10 输出约 `0.18m/s,+0.30rad/s`。
- `turn≈324°` 重获线后，视觉曾输出约 `+0.52rad/s`；`348°` 附近仍约 `+0.34rad/s`，说明出口左支会再次吸引视觉。
- `349.9°` gyro 正确确认出环；但进入 `SEEK_CROSSWALK` 后普通巡线很快又出现 `+0.54,+0.61` 等大左转，状态机虽然没有重新 FAST_ENTRY，车辆仍可能物理卷回环岛。

V11 改动：

1. `roundabout_exit_loss_speed: 0.18 -> 0.24`，220°~330°丢线继续固定左找但更快。
2. `peak>=330°` 武装出口航向锁；目标为 FAST_ENTRY 时记录的起始方向，对应累计角 `360°`。
3. 航向命令默认 `kp=0.010`，最大左 `+0.30`、最大右 `-0.12`、容差 ±8°。
4. 尚未对齐时视觉只保留 35% 权重；检测到视觉大左转 `>+0.18` 时，执行一次 1.5s gyro 航向接管，而不是 `w=0` 盲直。
5. 正式出环后保留 3.0s 航向参考；允许普通巡线与右修，仅对可疑大左转做一次 1.5s 接管，之后仍对大左转限幅。
6. 可疑左支帧不写入趋势历史，避免保护结束后旧历史再次把车向左拉。
7. 同圈二次识别的软件门保持：25s 冷却 + 本圈完成锁 + 第一次人行横道后 15s 第二环岛门。
