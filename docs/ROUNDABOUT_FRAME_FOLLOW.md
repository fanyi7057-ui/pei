# 环岛：原始流程与逐帧跟随

本次“原始/官方逻辑”指用户保存的 `src_first` 源快照，不是厂商认证或实车成功保证。原快照不修改。

## 流程

寻找入口 → 原始证据积分确认 → 沿线接近 → 左转进环并逐帧修正 → 环内逐帧跟随 → 出环保护 → 斑马线。

- 入口保留原积分门，而非单个强帧立即接管。强证据每帧加 1、弱证据加 0.35，无证据减 0.30，达到 2.4 才确认；原启动里程门仍有效。
- 接近段用原巡线的正/负纠偏，不再固定左偏。`roundabout_approach_distance_m` 是相对接近起点位移。
- 进环段用原左转基准加视觉 PD 修正，目标角速度不为负；达到进环位移或原时间兜底进入 FOLLOW。实际发布仍经过角速度平滑，方向切换不会瞬时完成。
- FOLLOW 根据可信轨迹修正，保留小幅右纠偏下限。原 ENTRY→FOLLOW 短时保护、蓝色边界保护、出口证据与出环提交段继续有效。
- 无可信线时用低速左弧恢复，超过 `roundabout_visual_loss_seconds` 立即发零速度，不等待平滑减速；暂停阶段超时转移，直到新帧重新确认，避免超时自动盲走。

## 每一帧是什么意思

每个**新处理帧**更新一次，不是预测未来尚未拍到的帧。采集线程仍只保留最新图像，控制器忙时会跳过旧帧，不积压录像帧。重复图像序号不参与确认或刷新可信时间。

沿用现有连续路径选取的误差、置信度和有效采样带，不另开相机。至少两条有效带、达到置信度门、误差有限，才可作为候选；相邻误差突跳时重新确认，连续稳定后可接受新轨迹。相机超时清除确认，但不重置丢线时间预算。

进环公式：`w = clamp(左转基准 + kp*误差 + kd*误差变化率, 0, 视觉角速度上限)`。

环内公式：`w = clamp(kp*误差 + kd*误差变化率, 小幅右纠偏下限, 视觉角速度上限)`。

误差先转换为底盘坐标，正角速度为左转。无法仅凭参数证明电机实车方向，现场仍看画面、状态和轨迹。

## 只改哪一组

日常打开 `ros2_ws/src/wheel_robot/config/race_tuning.yaml` 的 **E 段**。新字段均有中文单位、范围和调节效果：

| 参数 | 用途 |
|---|---|
| `roundabout_visual_enabled` | 1=新帧修正，0=原固定左转进环/旧 FOLLOW；接近段始终沿线 |
| `roundabout_visual_kp` | 偏离轨迹的纠偏力度 |
| `roundabout_visual_kd` | 对误差变化率的响应，过大易放大噪声 |
| `roundabout_visual_max_turn_speed` | 此控制器角速度限幅；不依赖普通巡线最大转向 |
| `roundabout_visual_min_confidence` | 可信线的置信度门 |
| `roundabout_visual_confirm_frames` | 新轨迹需连续多少个新处理帧 |
| `roundabout_visual_max_error_jump` | 何种跳变要重新确认 |
| `roundabout_visual_loss_seconds` | 低速恢复最长时间，之后停车等重新确认 |

保存文件约 0.5 秒后热加载；节点运行时生效，无需指令或重新编译。修改错误会整体拒绝，保留上一份完整值。原速度策略、平滑、边界/丢线保护仍参与实际输出；目标速度不等于所有阶段的恒定实际速度。

本次采用用户最新附件的 91 项保留值：普通目标速度 0.40、环岛目标 0.40、接近速度/位移 0.40/0.40、进环位移 0.30、姿态 0.15m/+25°；台阶关闭、普通预转向关闭。斑马线 30s/30s 时间门、3s 停车与清线、第二处确认后继续 1m 结束保持不变。保留的弯道封顶 5/8m/s 不是目标速度，不会令 0.40m/s 目标自动变成 5/8m/s。
