# TG0 跳台任务使用方法

此版本是跳台专项测试版。菜单和状态监视只观察程序状态，不会改变巡线、台阶锁定、起跳或落地控制。

## 每次上车后的顺序

1. 将完整 `robot` 文件夹上传为小车上的 `/home/orangepi/robot`；不要覆盖原有 `/home/orangepi/wheel_robot`。
2. SSH 登录橙派后运行：

   ```bash
   bash /home/orangepi/robot/tools/robot_menu.sh
   ```

3. 菜单选 `1` 编译。成功后不要退出此菜单，因为本次菜单会话会记住编译已通过。
4. 首次放到赛道前，选 `2`，再选 `1` 查看串口 `/dev/ttyUSB0`、相机和磁盘状态。
5. 选 `5` 做视觉与台阶预览。此项不启动底盘；确认小车屏幕上的相机画面、黑线和台阶检测正常后，用 `Ctrl+C` 停止。
6. 确认轮子离地后，可选 `4` 做支架联调。此项会启动底盘，但不会允许自主行驶。
7. 平地原地姿态正确时，可选 `3` 检查比赛姿态。确认车高、俯仰和相机视角后用 `Ctrl+C` 停止。
8. 赛道、急停和遥控接管均已确认后，选 `6` 启动正式任务。输入 `1` 后自动执行完整比赛，包括巡线、跳台、急弯、环岛、人行道和停车；输入 `0` 结束。

## 正式运行中的状态打印

正式节点每 **2.5 秒**打印三行 `状态[2.5s]`：

- 第一行：当前比赛阶段、圈数、底盘指令速度 `v`、转向 `w`、左转/右转方向，以及左右轮编码器反馈速度、编码器正/反转方向和这 2.5 秒内的平均加速度。
- 第二行：黑线是否识别、置信度、有效检测带数量、近/中/远误差和识别原因。
- 第三行：台阶是否识别、检测是否新鲜、距离、高度、置信度、确认帧数和当前跳台状态。

轮速单位是 `rad/s`，来自 `/robot_joint_states` 的实际编码器反馈；加速度单位是 `rad/s2`，为相邻两次状态打印之间的平均值。轮子显示“正转/反转”是编码器坐标方向，车体实际前进、左转、右转以同一行中的 `v`、`w` 和文字方向为准。若显示“无反馈”，先检查底盘节点是否已经由正式任务启动。

## 当前终端操作

- 输入 `1`：启动完整比赛。操作台会确认开始；台阶达到程序条件后自动执行跳跃，其余任务也连续自动运行。
- 输入 `0` 或按 `Ctrl+C`：结束本次比赛。

菜单 `7` 可以查看最近一次完整比赛日志；菜单 `8` 可再次打开本说明。
