# 5.1 跳台直接接管

## 想法

深度相机连续确认真实台阶后，直接把控制权交给跳台流程，不再依赖“已经转过 85 度”、固定赛道里程窗口或单一地图位置判断。

## 保留的安全条件

- 必须收到新鲜的深度检测。
- 检测器必须完成连续帧确认并发布 `detected=true`。
- 距离必须有效且不大于 1.05m。
- 高度必须在 0.025～0.085m。
- 置信度必须不低于 0.42。
- 只允许在正常比赛的三个寻线阶段接管，跳台完成后本圈不重复触发。

## 操作方式

- 正式任务输入数字 `1`：自动开始整场比赛；深度确认后自动执行完整跳台流程，并继续其他任务。
- 输入数字 `0` 或按 `Ctrl+C`：结束。

## 特点

- 优点：不会再发生“画面已经识别到跳台，但因为 85 度或里程门槛没有动作”。
- 风险：赛道上其他外形、高度和距离均相似的物体也可能满足检测，因此首次实车测试应使用手动模式并准备遥控急停。
- 待验证：接管距离、对正效果、起跳早晚、落地稳定性、完成后重新寻线能力。
