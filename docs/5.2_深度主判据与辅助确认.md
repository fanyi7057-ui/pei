# 5.2 深度主判据与辅助确认

## 想法

本版建立在 5.1 上，深度相机连续确认仍是跳台接管的主判据。在接管前增加软辅助确认，用于过滤单帧距离跳变或明显倾斜的目标，但不恢复地图里程和固定转角门槛。

## 辅助确认

- 最近 3 个有效深度距离的最大差值不超过 0.12m。
- 台阶前沿姿态有效时，角度绝对值不超过 0.30rad，横向偏移绝对值不超过 0.16m。
- 前沿姿态不可用时，可由连续黑线方向作为辅助：黑线置信度不低于 0.35，近点与中点误差差值不超过 0.35。
- 如果姿态和黑线辅助都暂时不可用，但深度持续稳定满 1.0s，则允许深度单独兜底确认。
- 辅助条件需要累计 3 帧，单帧失败只递减计数，不会立即清空全部证据。

## 操作方式

- 输入数字 `1`：启动完整比赛，之后自动执行巡线、跳台、急弯、环岛、人行道和停车。
- 输入数字 `0` 或按 `Ctrl+C`：结束。

## 特点

- 优点：比 5.1 更能抑制距离突然跳变和明显斜对台阶的误接管。
- 风险：辅助阈值尚未实车验证，可能让接管比 5.1 晚约数帧；深度稳定兜底用于避免永久等待。
- 终端观察：状态行显示 `版本=5.2`，并显示 `stable/pose/line/fallback/frames` 辅助确认详情。
